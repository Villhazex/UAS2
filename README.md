# LumiTask

LumiTask adalah aplikasi manajemen tugas berbasis PHP Native dengan konsep Object-Oriented Programming (OOP).  
Project ini dibuat untuk membantu pengguna mengelola tugas harian dengan tampilan modern, sederhana, dan mudah digunakan.

![Preview LumiTask](image/image.png)

---

## ✨ Features

- 🔐 Authentication System (Login & Register)
- ✅ Create, Update, Delete Task
- 📌 Task Priority
- 📂 Task Categories
- 📊 Task Statistics
- 👤 Session-Based User System
- 🎨 Modern UI Design
- 🧩 Object-Oriented Programming (OOP)
- 🗂️ Dynamic Task Management
- 📱 Responsive Layout

---

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/Villhazex/UAS2.git
```

---

### 2. Move Project

Pindahkan folder project ke:

#### XAMPP

```bash
htdocs/
```

#### Laragon

```bash
www/
```

---

### 3. Import Database

1. Buka phpMyAdmin
2. Buat database baru:

```sql
todo_oop
```

3. Import file SQL yang tersedia

---

### 4. Configure Database

Edit file:

```bash
config/database.php
```

Sesuaikan:

```php
private $host = "localhost";
private $username = "root";
private $password = "";
private $database = "todo_oop";
```

---

### 5. Run Project

Buka browser:

```bash
http://localhost/UAS2
```
